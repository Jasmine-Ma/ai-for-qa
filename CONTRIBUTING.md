# Contributing to AI for QA

Thanks for your interest in contributing! This repo is a learning resource for QA engineers, and we welcome all kinds of participation.

## Ways to Contribute

### Ask Questions & Share Ideas
The best way to get involved is through [GitHub Discussions](https://github.com/Jasmine-Ma/ai-for-qa/discussions). Use the Q&A category to:
- Ask how to apply AI to your specific testing challenges
- Share prompts or workflows that worked well for you
- Discuss tools, techniques, and lessons learned

### Submit Examples
Have a useful AI-for-QA script or workflow? Open a pull request:

1. Fork the repo and create a branch
2. Add your example under `examples/` in its own directory
3. Include a clear docstring, inline comments, and a `requirements.txt`
4. Open a PR describing what the example demonstrates

### Report Issues
If you find a bug or something unclear, [open an issue](https://github.com/Jasmine-Ma/ai-for-qa/issues).

## Guidelines

- Keep examples self-contained and easy to follow
- Use clear variable names and comments for readability
- Don't commit API keys, credentials, or large data files
- Test your examples before submitting
